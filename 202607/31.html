Dive #188 ダイビング・カリキュレーターの紹介再び

ダイビング・カリキュレーターという Web ツールを作って公開しています。ダイビング計画やログ付けを支援する Web ツールです。

  • ダイビング・カリキュレーター: https://mitsugu.github.io/diveplanner/
  • ソース一式: https://github.com/mitsugu/diveplanner
  • ライセンス: Apache 2.0 License

以下の計算機能があります。

1. EAN (ナイトロックス) 計算機

酸素濃度から MOD、PO2、EAD (空気換算深度) を計算します。

2. RMV (呼吸ガス消費量) 計算機

ログデータ (残圧、時間、水深) からあなたのRMVを算出します。

3. ガス管理計画計算機

RMV、R-Gas (緊急用)、T-Gas (折り返し残圧: Turn Pressure) を計算します。

RMV に基づくリターンプレッシャー、50bar ルールに基づくリターンプレッシャー、1/3 ルールに基づくリターンプレッシャーなどを計算することができます。

ただしレクリエーショナル・ダイビングを想定したものであり、無減圧潜水を前提とします。また減圧用ガスやステージボトルなど、複数のガスを使用するテクニカルダイビングには対応していません。

このダイビング・カリキュレーターは html、css、Pure JavaScript で実装されています。そのためすべてのリソースをスマホなどにダウンロードすると、携帯の電波が届かない場所でも使うことができます。

もちろん電波が届く場所であれば、一式をダウンロードしなくてもお使いいただけます。
